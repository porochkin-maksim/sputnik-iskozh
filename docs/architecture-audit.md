## Проблемы

### 🔴 Нет тестов

| | |
|---|---|
| **Где** | `tests/Unit/` и `tests/Feature/` — пусты (только `.gitkeep`) |
| **Что** | Весь runtime-код (backend + frontend) не покрыт автотестами |
| **Риск** | Любое изменение может сломать функционал без возможности обнаружить это до продакшена |
| **Статус** | ❌ Не начат |

---

### 🟠 Нет PHPStan / Psalm

| | |
|---|---|
| **Где** | Весь проект |
| **Что** | Архитектурный guard (`make architecture`) — только grep-based. Не ловит type errors, несуществующие классы, неверные аргументы (LSP показывает такие ошибки в существующем коде) |
| **Риск** | Ошибки типов уходят в продакшен |
| **Статус** | ❌ Не начат |

---

### 🔵 Acquiring — только VTB, webhook-подпись

| | |
|---|---|
| **Где** | `core/Domains/Billing/Acquiring/`, `ProviderEnum` |
| **Что** | Единственный провайдер. `makeHash()` использует HMAC-SHA256 с секретом (`API_VTB_WEBHOOK_SECRET`), `HandleSubmitWebhookCommand` дополнительно опрашивает статус у провайдера через `ProviderGateway::isPaid()` |
| **Риск** | Низкий — подпись защищена секретом, вебхук подтверждается только при реальной оплате; расширение провайдеров не планируется |
| **Статус** | ✅ Исправлено (HMAC-SHA256 + секрет из env + опрос статуса) |

---

### 🔵 Нет ESLint / Prettier для фронта

| | |
|---|---|
| **Где** | Весь JS/Vue-код |
| **Что** | Нет автоматического форматирования и линтинга JS/Vue |
| **Риск** | Низкий — проект использует Composition API + `<script setup>`, стиль достаточно единообразен |
| **Статус** | ❌ Не начат (упомянут в `FRONTEND_STANDARDIZATION_PLAN.md` как будущий improvement) |
