# Vue 3 + Vite Conventions

## Стек
- Vue 3 с Composition API (предпочтительно `<script setup>`)
- Vuex 4 для управления состоянием
- Vite для сборки
- Bootstrap 5 (css + js)
- Sass для стилей
- Frontend tooling запускать только через Docker/Sail: `make yarn ...`, `make node ...`, `make yarn-build`,
  `make yarn-watch`.
- Локальные `npm`, `yarn`, `node`, `vite` для проектных команд запрещены.

## Компоненты
- Компоненты хранятся в `resources/js/components/`
- Используй однофайловые компоненты `.vue`
- Именование: PascalCase для файлов и компонентов

## Blade + Vue компоненты
- Внутри `.vue` SFC — self-closing теги разрешены (`<Component />`).
- В `.blade.php` (серверный HTML) **запрещён self-closing синтаксис** для Vue-компонентов (`<component />`). HTML-парсер браузера не распознаёт `/>` для не-void элементов и трактует их как открывающие теги без закрывающих. При наличии нескольких Vue-компонентов на одном уровне это приводит к вложенности и исчезновению последующих компонентов.
- **Правильно:** `<component>` ... `</component>` — всегда явный закрывающий тег.
## Роутинг и редакторы
- Серверный рендеринг Laravel остаётся базовым способом навигации; клиентский роутинг вводится только при явной необходимости.
- Rich text редакторы и другие тяжёлые UI-встраивания подключай только через изолированные components/adapters, не размазывая их логику по страницам.

## Стили
- Основной CSS через Bootstrap 5
- Кастомные стили в `resources/sass/`
- Используй Vite для компиляции Sass через `make yarn-build` или `make yarn-watch`
